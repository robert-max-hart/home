World of Tanks: Modern Armor

modernarmor.worldoftanks.com

World of Tanks: Modern Armor is a free-to-play massively mulitplayer vehicle combat game that is avaiable on the Xbox and Playstation consoles. I started out as a QA Engineer on the Platform Integration team - essentially, the team responsible for the web-service backend components the game uses (authentication, payment processing, etc). As a QA Engineer, I engineered testing frameworks in PyTest to test these services, and soon became Lead QA Engineer of a team of five engineers, doing mostly managerial and lead stuff at that point.
I then moved to become a senior UX Engineer, responsible for implementing the screen designs and art for the game, using a stack of C++, Python, LUA, and Actionscript (via a middleware layer called Scaleform). In my extensive time here I've touched at least every aspect of every screen in some way, but some highlights of large-scale contributions I've made include: creating from scratch the Commanders system screens and Custom Garage screens, refactoring the currency system used to implement additional event-based currencies, and recreating new shared components to be ever-more efficient in a game whose memory footprint continues to increase against fixed hardware specs.

Component-based garage interface pairing a real-time 3D tank render with a fully data-bound stats panel — penetration, damage, hit points, and vision values update live from game state. Reusable widget patterns run throughout: the equipment/consumables/camouflage slot grids, the tank carousel, and the currency/XP readouts are all built from the same underlying component system, reused across 50+ garage screens.

Branching tech-tree UI visualizing a vehicle's upgrade path, with distinct visual states for completed, active, and locked nodes and a contextual detail panel that updates dynamically to describe whatever item is currently selected. The horizontally scrollable tree and the 3D vehicle preview run side-by-side, tying progression logic directly to the rendered asset.

Three-panel commander management UI: a recruitable roster grid with per-card selection and assignment states on the left, a rendered 3D character portrait in the center, and a skill-tree panel on the right tracking locked/unlocked abilities and XP-to-next-skill progress. Coordinates several interconnected, independently updating data panels around a single 3D-rendered focal point.
